# 意图识别数据集——汇总版（Intent Recognition Dataset — Summary Collection）

## 概述

本数据集将五个子数据集（交会场景 `Dataset_new2/`、阻扰场景 `Dataset_Obstruction/`、探测场景 `Dataset_Detection/`、潜伏场景 `Dataset_Lurk/`、混合场景 `Dataset_Mix/`）合并为一个统一的汇总数据集。所有样本的 `X_now` / `X_next` / `Y` 格式与各子数据集完全一致。

与各子数据集的关键区别在于：本数据集在合并时**已对所有样本进行全局随机打乱**，使来自不同场景的样本充分混合。因此不再保留各场景或各 N 值的原始分组顺序，便于下游训练直接按需划分训练/测试/验证集。

---

## 文件清单与角色

| 文件 | 角色 | 说明 |
|------|------|------|
| `X_now.csv` | 输入特征 | 追踪航天器相对于目标（位于 LVLH 系原点）的近期 10 个时间步的相对状态 |
| `X_next.csv` | 预测目标 | 紧接 `X_now` 之后的下 10 个时间步的相对状态（可能包含 CW 外推补齐点） |
| `Y.csv` | 标签 | 每批次的场景标签：目标数量、全局最小距离、最近与最远目标位置向量间的夹角 |

> **对应关系**：三个文件按行严格一一对应，**已在合并时统一打乱**。第 *i* 行 `X_now`、第 *i* 行 `X_next`、第 *i* 行 `Y` 来自同一批次。绝对不可单独打乱任一文件的顺序。

### 公共物理环境参数

| 参数 | 符号 | 值 | 单位 |
|------|------|-----|------|
| 轨道半径 | r | 6371 + 480 = 6851 | km |

### 坐标系

本地垂直/本地水平（LVLH）坐标系：原点位于目标航天器质心，x 轴沿径向向外，z 轴垂直于轨道平面（沿角动量方向），y 轴完成右手系（沿轨/切向）。所有位置和速度均为追踪航天器相对于目标在该系下的分量。

## 数据结构详细说明

### 通用格式说明

- 每个 CSV 文件首行为列名（单列），之后每行为一个样本。
- `X_now.csv` 和 `X_next.csv` 的每行采用**嵌套列表字符串**格式：外层列表包含 10 个内层列表（对应 10 个时间步），每个内层列表包含 N×6 个浮点数（N 个目标 × 6 维状态），以 `%.4f` 格式保留 4 位小数，逗号后一个空格分隔。
- `Y.csv` 的每行为一个包含 3 个元素的列表字符串：`[N, min_distance, phi]`。
- **重要**：不同来源（N=2/3/4）的样本中，N 值不同，因此 `X_now` 和 `X_next` 每行内层列表的元素个数也不同（见下表）。

### X_now.csv

| 属性 | 说明 |
|------|------|
| 列名 | `X_now` |
| 物理意义 | 追踪航天器相对于目标的近期相对运动状态（观测窗口） |
| 数据结构 | 字符串格式嵌套列表 `[[step1], [step2], ..., [step10]]` |
| 时间步数 | 10 |
| 采样间隔 | h = 1 s |
| 总时间跨度 | 9 s（10 个点，间隔 1 s） |

**单步内层列表结构**（按目标依次排列）：

```
[x1, y1, z1, vx1, vy1, vz1,  x2, y2, z2, vx2, vy2, vz2,  ...,  xN, yN, zN, vxN, vyN, vzN]
```

| 分量 | 物理意义 | 类型 | 单位 | 数量 |
|------|---------|------|------|------|
| xi | 目标 *i* 的 x 方向相对位置（径向） | float | km | N 个 |
| yi | 目标 *i* 的 y 方向相对位置（切向） | float | km | N 个 |
| zi | 目标 *i* 的 z 方向相对位置（法向） | float | km | N 个 |
| vxi | 目标 *i* 的 x 方向相对速度 | float | km/s | N 个 |
| vyi | 目标 *i* 的 y 方向相对速度 | float | km/s | N 个 |
| vzi | 目标 *i* 的 z 方向相对速度 | float | km/s | N 个 |

> 每行共有 10 个内层列表，每个内层列表含 N×6 个 float。N 由样本来源决定（2 / 3 / 4）。

### X_next.csv

| 属性 | 说明 |
|------|------|
| 列名 | `X_next` |
| 物理意义 | 紧接 `X_now` 之后的下 10 个时间步的相对运动状态（预测目标窗口） |
| 数据结构 | 与 X_now 一致 |
| 时间步数 | 10 |
| 采样间隔 | h = 1 s（原始仿真部分）或 T = 60 s（CW 外推补齐部分） |
| 总时间跨度 | 取决于数据来源（混合 h 和 T 步长） |

> `X_next` 是截取/补齐后序列的第 11~20 步，**不是**从 X_now 终点独立递推生成的。对于原始轨迹足够长的部分，`X_next` 就是真实仿真数据；对于原轨迹长度不足需要外推补齐的部分，`X_next` 中会混入 CW 外推点。

### Y.csv

| 属性 | 说明 |
|------|------|
| 列名 | `Y` |
| 格式 | `[N, min_distance, phi]` |

每行三个值：

| 分量 | 物理意义 | 类型 | 单位 | 取值范围 |
|------|---------|------|------|---------|
| N | 该批次目标数量 | int | — | {2, 3, 4} |
| min_distance | 所有目标在所有时刻中距离 LVLH 原点（参考点）的最小值 | float | km | (0, 200) |
| phi | 最小距离时刻，距离原点最近与最远的目标位置向量之间的夹角 | float | rad | [0, π] |

**phi（φ）的计算方法**：在全局最小距离对应的时刻，分别计算各目标到原点的距离；找出距离最小（最近）和距离最大（最远）的两个目标；phi = arccos( (r₁·r₂) / (|r₁|·|r₂|) )，其中 r₁、r₂ 分别为最近和最远目标在该时刻的位置向量。

**min_distance 的计算方法**：拼接所有目标的所有 20 个时间步（共 N × 2 × real_length 个距离值）的距离序列，取全局最小值。

## 行对应关系

**合并前**：每个子数据集内部，X_now / X_next / Y 三个文件已由各自的 MATLAB 脚本和 merge 脚本保证行数相等、行行对应。

**合并过程**（`merge_csv_Summary.py`）：
1. 分别读取五个子数据集的 X_now.csv / X_next.csv / Y.csv，去掉各自的 header 行。
2. 将所有数据行纵向拼接为完整的三份数据列表（每份 217,642 行）。
3. 生成一组全局随机排列的索引，对三份数据列表**同时施加相同排列**。
4. 写入合并后的 X_now.csv / X_next.csv / Y.csv，添加 header 行。

> 因此本数据集中，三个 CSV 文件的行序**完全一致**，第 *i* 行 `X_now` 对应第 *i* 行 `X_next` 和第 *i* 行 `Y`。由于已统一打乱，原始子数据集的内部顺序（如 Mix2→Mix3→Mix4 等）已被破坏，样本呈全局随机排列。

各子数据集的数据预处理流程（轨迹筛选、随机分批、截取与外推、序列切分、标签计算）详见各自的 README。本数据集**不再进行额外的归一化、标准化、滤波或缺失值填补**。

## 使用注意事项

1. **对齐要求**：三个 CSV 文件必须始终保持相同行序。任何划分、采样、数据增强操作需要同时对三个文件施加一致的索引变换。
2. **已打乱**：本数据集已在合并时完成全局随机打乱，因此可直接按比例切分训练/测试/验证集（如取前 80% 为训练、后 20% 为测试），无需额外打乱。若需进一步重排，必须对三个文件同步进行。
3. **变长样本**：不同行的内层列表元素数不同（N×6 分别为 12 / 18 / 24），这对应不同的目标数量 N。神经网络模型需要处理变长输入，或按 N 分组训练。N 值本身也可从 Y.csv 的 Y[:,0] 中直接获取。
4. **混合步长**：`X_next` 的后部可能包含 CW 外推点（步长 T=60 s），这与 `X_now`（全为 h=1 s 步长）的物理时间尺度不一致。如果下游任务对时间一致性有严格要求，需要考虑只使用原始长度充足的样本，或对此做适配处理。
5. **未归一化**：数据未经过任何归一化或标准化。位置量级约 0~200 km，速度量级约 0~0.1 km/s。训练神经网络时**强烈建议**按特征维度进行 z-score 标准化或 Min-Max 归一化。
6. **无缺失值**：所有样本均为有效轨迹，不包含 NaN 或缺失值。
7. **数据解析**：读取 CSV 后，每行数据为字符串，需要用 `ast.literal_eval` 或 `json.loads` 解析为嵌套列表（注意 Python 中解析后为 float / int 类型而非字符串）。
8. **CW 模型假设**：CW 外推基于 CW 方程线性化假设（圆轨道、近距离、无摄动），与真实非线性动力学存在模型误差。`X_next` 中外推部分的数据保真度低于真实仿真部分。
9. **场景多样性**：本数据集汇集了交会（远距窄扇面）、阻扰（近距广域）、探测（中距全角）、潜伏（远距全角）四个单场景及其混合场景的轨迹数据，状态分布极为丰富，适合训练具备**跨场景泛化能力**的意图识别模型。
10. **场景来源不可追溯**：本数据集不记录每个样本来自哪个子数据集或哪个场景。若下游任务需要区分场景来源，请使用各场景的独立子数据集（如 `Dataset_new2/` 或 `Dataset_Obstruction/`）。
